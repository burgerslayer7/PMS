# Pokémon Mount System v0.1.0

First clean-room public build of the mount foundation for Gen1Recomp++ API v2.

Highlights:

- Red, Blue, Yellow, Gold, Silver and experimental Crystal manifest support.
- Ground Ride, Visible Surf and altitude-based Flight.
- 40 species / 42 mode entries, including Arcanine, Lapras, Charizard and Ho-Oh.
- Bundled attributed 001–251 PokéPC fallback; no PokéPC runtime dependency.
- Battle/map/save restoration and duplicate-follower render ownership.
- Battle Art and Dramaless Voxel Companion support.
- Stadium Gen1/Gen2 public model tagging with automatic per-species fallback.
- Wild Skies cooperative flight marker.
- Debug HUD, structured logs, 251-asset validation and Gen1/Gen2 loader gates.

Install the attached `pokemon-mount-system-v0.1.0.zip` directly through
**MODS → Import mod .zip**. No other mod is required.

Runtime controls and short test cards are in `docs/TESTING.md` inside the ZIP.
